# Capturing README Screenshots

1. Open this project in VS Code and press **F5** (Extension Development Host).
2. Open a Git repo with:
   - At least 2–3 stashes (enable **Group by Branch** for the Stashes shot)
   - Staged and working changes in **Working Changes**
3. Open the **Stasher** Activity Bar container.
4. Capture **Working Changes** panel → save as `docs/screenshots/working-changes.png`
5. Capture **Stashes** panel (branch groups expanded) → save as `docs/screenshots/stashes.png`
6. Keep images under ~500 KB if possible (crop to the sidebar panel only).

Replace the existing mockup files in `docs/screenshots/` with these captures before publishing.
